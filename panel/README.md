# Panel

Authenticated management application for the team management product. This is the primary MVP
application.

Stack: React, TypeScript, Vite, React Router, TanStack Query, Tailwind CSS.

Pages: `/login`, `/dashboard`, `/organization`, `/organization/members`, `/teams`, `/teams/:id`,
`/projects`, `/projects/:id`, `/tasks`, `/goals`, `/checkins`, `/settings`.

The application is implemented in Stage 12 of `IMPLEMENTATION_PLAN.md`. This directory is currently
a placeholder created in Stage 0.
